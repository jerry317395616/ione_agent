# Wiki Knowledge

Use the manager MCP tools to maintain Wiki content. Keep one application or knowledge domain in one Space and organize pages as chapters.

## Workflow

1. Discover `Wiki Space` and `Wiki Page`, then inspect both metadata definitions.
2. Search existing spaces and pages before creating content.
3. Build a short chapter plan. Create the Space first only when it does not exist.
4. Create or update page drafts using fields confirmed by metadata.
5. For long source material, attach a private `.md` evidence file and keep links and attribution.
6. Read each saved page back and report its exact name and publication state.

## Rules

- Do not reproduce copyrighted pages verbatim. Translate or summarize within source limits and cite the source URL.
- Do not publish, delete or replace an existing page without explicit user intent and an available controlled tool.
- Keep headings, lists, tables and code blocks valid Markdown.
