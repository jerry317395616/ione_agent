# child 站点业务域与主数据边界

## 主数据归属

| 业务对象 | 主数据来源 | 其他应用的使用方式 |
| --- | --- | --- |
| 学生、班级、学年、课程 | Education | 童健云按链接或稳定业务键引用，不复制维护 |
| 食谱、餐次、菜品、食材、带量 | 童健云 | ERPNext 可根据需求生成采购草稿 |
| 就餐人数、请假、缺勤 | Education 与童健云业务记录 | 分析时按日期和班级关联，保留来源 |
| 健康档案、生长测量、过敏、特殊膳食 | 童健云 | 仅授权岗位可见；最小化读取 |
| 供应商、物料、采购、库存、财务 | ERPNext | 童健云提供需求，不复制供应商主数据 |
| 待办、附件、备注、通知 | Frappe 通用能力 | 附着到所属业务记录 |

## 典型闭环

### 周食谱到采购

食谱导入或创建 → 解析预览 → 人工确认歧义 → 写入并回读 → 营养与带量分析 → 结合班级和就餐人数计算需求 → 生成采购草稿 → 人工审核提交。

### 每日到园与就餐

Education 班级和学生 → 当日考勤/请假 → 确认可就餐人数 → 记录调整原因 → 反馈食材执行与留样 → 汇总偏差。

### 健康与特殊膳食

授权健康记录 → 识别过敏或特殊膳食约束 → 检查食谱冲突 → 形成替代建议 → 由责任人确认 → 保留可审计记录。不要由 Agent 自动修改儿童健康结论。

## 冲突处理

1. 实时 Frappe 记录优先于会话记忆和文档描述。
2. 同一对象在多个应用重复时，以本表主数据来源为准，其他记录只做关联或历史证据。
3. 日期、班级或人员匹配不唯一时停止写入，展示候选并请求确认。
4. 统计口径必须写明是否包含请假、缺勤、教职工、临时加餐和损耗。
