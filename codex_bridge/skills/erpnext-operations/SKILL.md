# ERPNext 经营管理

## 工作流程

1. 用 `frappe_get_site_catalog` 的 `app=erpnext` 查看当前用户可用的对象；不要凭记忆猜测 DocType 或字段。
2. 查询公司、客户、供应商、物料、仓库、币种、会计期间等前置主数据。
3. 写入前读取目标 DocType 元数据和已有单据，用业务键检查重复。
4. 只创建或修改草稿；对子表字段严格使用元数据返回的字段名。
5. 写入后回读并报告编号、状态、关键金额/数量、缺失值和下一项人工动作。

## 控制要求

- 不提交、取消、删除、过账、付款、对账、关账或审批。
- 不臆造公司、科目、仓库、税模板、客户、供应商、物料、批次或序列号。
- 不静默修改数量、价格、税费、交期、账户、库存地点或成本中心。
- 遇到会计、库存、工资等高影响操作，先列出将写入的关键值再创建草稿。
- 采购询价到发票流程可加载 `erpnext-procurement` 获取更细的步骤。
